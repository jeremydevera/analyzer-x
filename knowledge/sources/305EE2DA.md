It lists a syllabus of lessons (hello world, control flow, lists, loops, functions, strings), three sample projects, a rating summary, a few learner reviews and some related courses. It is mostly a menu and sales page, so it teaches almost nothing by itself: each lesson gets one or two sentences saying what it covers. The text never mentions trading, markets, prices, backtests or money, so almost every trading topic is "not covered". The only use for this repo would be as a pointer to a place where someone could learn basic Python.
