## What it is

This is the code companion to the book *Python for Finance -- Mastering Data-Driven Finance* (2nd edition) by Yves Hilpisch. The README says the repository holds all the Python code and Jupyter notebooks of the book. It explains how to set up the Python packages with conda, points to an online "Quant Platform" where the notebooks can be run after registering, and ends with adverts for the author's company, trainings and a university certificate. It does not say what finance topics the notebooks cover, and it teaches no trading method itself.

## What I did not read, and doubts

- I read only the README (314 words, all of it). I did not read a single notebook, the yaml file, or the book. So nothing here says what the notebooks actually teach about finance or trading.
- More than a third of the README is marketing for the author's own company: the Quant Platform, the trainings, the certificate, and two books. Treat those sections as adverts, not lessons.
- The setup advice is dated: it is pinned to Python 3.6 / 3.7 and an old TensorFlow problem, and the README does not say whether the promised update was ever made. The shell steps are said to work on Mac OS only, so they may not work on this Windows PC as written.
- The README gives no licence, so whether the code may be reused here is not stated.
- The saved text holds a broken character before "Dr. Yves J. Hilpisch" (most likely a copyright sign lost in saving); I did not quote it.
- For our project this source is worth nothing on its own: no costs, no testing on unseen data, no sizing, no stops, no claim we could check.
