## Claims we could test on our own data

These are my suggestions for how this repo's crypto backtests could confirm or refute what the description says. The book
does not describe these tests; the page gives no method.

1. **"findings are likely false, due to rampant backtest overfitting"** Choose strategies on older days only, judge
   them on newer days they never saw, and set them beside random entries picked the same way, with the number of
   combinations tried printed beside the result. The repo has done this several times. The Pro Trader research (Oct 20,
   2026) chose 2,255 picks and they made −$0.23 a trade over 220,977 unseen trades, against −$0.22 for random entries;
   the confluence research's picks were +0.033R a trade before fees over random, a 90% range of −0.079R to +0.146R.
   Both agree with the claim. A new test would only add evidence if it is run the same way.
2. **"Incorrect specification choices."** Take a winning row and re-run it with nearby settings (a slightly different
   lookback, stop or target). If the profit vanishes when one setting moves one step, the winner was a lucky setup, not a
   finding. Also check whether a ranking holds on two nights' stores: the repo measured that a rule set's rank carried
   over at only about +0.04 across held-out months for Backtest v4.
3. **"They justify their chosen model specification in terms of correlations" / "do not propose experiments for
   falsifying causal mechanisms."** For any strategy that looks good, write down the reason it should work before
   looking at new data (for example, *it wins when funding is extreme*, or *it wins only when BTC is rising*; my
   made-up examples, not the book's). Then split
   its unseen trades by that condition. If the edge is not bigger when the reason is present, the reason is refuted
   even if the total looks fine.
4. **The multiple-testing titles in the reading list.** Compare the best of N real strategies with the best of N random
   ones, not with zero. Backtest v3's proof already does a version of this (a strict bar of α = 0.05 / 63 and 200
   random runs per coin).
5. **Type-A versus type-B spurious claims.** Cannot be tested from this page: it names the two types but does not
   define them.
